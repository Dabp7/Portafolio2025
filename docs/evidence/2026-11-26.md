# Verificación del rediseño

Entorno: Windows 10, Node.js 22.15.0, npm 10.9.2, Chromium de Playwright.

- `npm ci`: aprobado.
- `npm run lint`: aprobado.
- `npm run build`: aprobado, bundle React/Vite generado desde el código fuente.
- `npm run verify:dist`: aprobado, assets, PDF y hosting.
- `npm run test:e2e`: cuatro pruebas aprobadas, escritorio y móvil.

Los recorridos comprueban filtros, apertura de casos, Escape, restitución de foco, menú móvil, enlaces de contacto, descarga de PDF, ruta anterior y ancho sin desbordamiento horizontal.

Esta evidencia corresponde al rediseño con tres proyectos planificados. Al publicar las nuevas demos se actualizará su contenido y la suite.
