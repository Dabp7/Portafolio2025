# Verificación del portafolio con proyectos implementados

Windows, Node22.15.0, npm10.9.2 y Chromium de Playwright.

- `npm run lint`: aprobado.
- `npm run build`: aprobado.
- `npm run verify:dist`: aprobado, assets, PDF y Firebase.
- `npm run test:e2e`: cuatro pruebas aprobadas, escritorio y móvil390px.

Cinco casos públicos, filtros y estado vacío, enlaces reales de los tres nuevos repositorios, modales, Escape y restitución de foco, navegación móvil, copia real al portapapeles, descarga real del CV, PDF válido y ruta anterior comprobados. Sin errores JavaScript ni desbordamiento horizontal.

Las capturas de SuperKinal, DocumentFlow, ReconcileLab y POS provienen de sus demos con datos ficticios. La captura del POS corresponde a la web; su prueba Android está enlazada separadamente. Ventas Online conserva una ilustración conceptual identificada.

Los casos enlazan videos y decisiones. Los datos biográficos y el CV se conservan del material aprobado. No se desplegó en Firebase ni se crearon recursos AWS.
