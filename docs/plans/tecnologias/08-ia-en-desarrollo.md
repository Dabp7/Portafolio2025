# Plan de práctica de IA en el proceso de desarrollo

## Dónde se aplica

Todos los repositorios.

## Qué practicar

Preparar contexto, acotar una SPEC, pedir casos límite, separar implementación y revisión y comprobar la salida.

## Evidencia para el portafolio

SPEC, diff pequeño, prueba de regresión y evidencia con comando, commit y resultado.

## Decisiones de implementación

No convertir uso de Claude en afirmaciones de entrenamiento de modelos. No copiar configuración interna de trabajo; escribir instrucciones propias y reproducibles.

## Criterio para avanzar

Explicar la decisión con un caso de fallo y reproducir la comprobación desde el README. Añadir una tecnología nueva solo si resuelve un problema pendiente del proyecto.
