# Plan de práctica de React Native y SQLite

## Dónde se aplica

POS Sandbox.

## Qué practicar

Persistencia transaccional, ciclo de vida, recuperación tras cerrar la app y adaptadores de dispositivos.

## Evidencia para el portafolio

Video en emulador Android con venta offline, cierre del proceso y sincronización sin duplicados.

## Decisiones de implementación

Usar Expo SDK estable compatible con sus paquetes y expo install. La ruta web no reemplaza la prueba nativa de SQLite.

## Criterio para avanzar

Explicar la decisión con un caso de fallo y reproducir la comprobación desde el README. Añadir una tecnología nueva solo si resuelve un problema pendiente del proyecto.
