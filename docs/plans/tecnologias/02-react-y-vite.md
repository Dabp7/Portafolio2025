# Plan de práctica de React y Vite

## Dónde se aplica

Portafolio y paneles de DocumentFlow y ReconcileLab.

## Qué practicar

Diseñar estados de carga, error, vacío y éxito; formularios, navegación accesible y consumo de contratos.

## Evidencia para el portafolio

Un recorrido de usuario con pruebas de error de red y teclado; componentes por responsabilidad.

## Decisiones de implementación

Conservar las versiones compatibles del proyecto y lockfile. Next.js se reserva para una necesidad concreta de servidor o SEO; no se añade junto a Vite en el mismo frontend.

## Criterio para avanzar

Explicar la decisión con un caso de fallo y reproducir la comprobación desde el README. Añadir una tecnología nueva solo si resuelve un problema pendiente del proyecto.
