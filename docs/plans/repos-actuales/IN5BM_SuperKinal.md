# Plan de mejora de IN5BM_SuperKinal

Repositorio: https://github.com/Dabp7/IN5BM_SuperKinal

## Problema que resuelve

Gestión de inventario, compras y facturación en escritorio.

## Tecnologías

Java, JavaFX, JDBC, MySQL y Maven.

## Backlog ordenado

- [ ] Capturas reales de clientes, productos y facturación; video breve con datos ficticios.
- [ ] Verificar en una instalación limpia la base nueva y la migración documentada.
- [ ] Revisar que las pruebas Java y el workflow se puedan ejecutar desde el README.
- [ ] Explicar decisiones MVC, transacciones y validación; publicar un ejemplo antes y después de una corrección.

## Primera tarea

Crear una demo reproducible con base ficticia.

## Criterio de cierre

Una persona ejecuta la aplicación y las pruebas sin depender del equipo original.

## Entrega en GitHub

Trabajar en una rama, comprobar los cambios y abrir un PR con comandos ejecutados y resultados. Mantener el propósito académico del proyecto; añadir evidencia técnica antes de multiplicar funcionalidades. En el portafolio describir solo lo que esté implementado.
