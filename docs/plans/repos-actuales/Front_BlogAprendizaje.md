# Plan de mejora de Front_BlogAprendizaje

Repositorio: https://github.com/Dabp7/Front_BlogAprendizaje

## Problema que resuelve

Lectura y participación en un blog conectado a una API.

## Tecnologías

React, Vite, Axios y React Router.

## Backlog ordenado

- [ ] Documentar URL de API y variables de ejemplo.
- [ ] Estados de carga, vacío, error y reintento en cada consulta.
- [ ] Probar lectura de publicaciones y envío válido e inválido de comentarios.
- [ ] Capturas, despliegue de demo y enlace al backend.

## Primera tarea

Un recorrido completo de lectura y comentario.

## Criterio de cierre

Con API detenida el usuario entiende el error; con API activa puede completar el recorrido.

## Entrega en GitHub

Trabajar en una rama, comprobar los cambios y abrir un PR con comandos ejecutados y resultados. Mantener el propósito académico del proyecto; añadir evidencia técnica antes de multiplicar funcionalidades. En el portafolio describir solo lo que esté implementado.
