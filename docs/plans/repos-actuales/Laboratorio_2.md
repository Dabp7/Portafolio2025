# Plan de mejora de Laboratorio_2

Repositorio: https://github.com/Dabp7/Laboratorio_2

## Problema que resuelve

Gestión de mascotas y citas en un ejercicio de adopción.

## Tecnologías

Node.js, Express, MongoDB y JWT.

## Backlog ordenado

- [ ] Actualizar URL de clonación y documentación real de arranque.
- [ ] Validar disponibilidad y evitar citas simultáneas incompatibles.
- [ ] Probar roles y acceso a datos del propietario.
- [ ] Añadir seed sintético y CI; mantenerlo como antecedente académico.

## Primera tarea

Definir y probar la regla de reserva de cita.

## Criterio de cierre

Dos solicitudes simultáneas no reservan el mismo horario si el contrato lo impide.

## Entrega en GitHub

Trabajar en una rama, comprobar los cambios y abrir un PR con comandos ejecutados y resultados. Mantener el propósito académico del proyecto; añadir evidencia técnica antes de multiplicar funcionalidades. En el portafolio describir solo lo que esté implementado.
