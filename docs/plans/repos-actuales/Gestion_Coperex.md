# Plan de mejora de Gestion_Coperex

Repositorio: https://github.com/Dabp7/Gestion_Coperex

## Problema que resuelve

Gestión de empresas y exportación de reportes.

## Tecnologías

Node.js, Express, MongoDB, JWT y ExcelJS.

## Backlog ordenado

- [ ] Probar autorización administrativa en cada ruta, no solo en login.
- [ ] Definir filtros combinados y orden estable con paginación.
- [ ] Probar que el archivo Excel coincide con el filtro y conserva tipos esperados.
- [ ] Actualizar ejemplos de configuración, seed y CI.

## Primera tarea

Tests de autorización y exportación.

## Criterio de cierre

Una cuenta sin permiso no administra empresas; el Excel coincide con la consulta y se abre correctamente.

## Entrega en GitHub

Trabajar en una rama, comprobar los cambios y abrir un PR con comandos ejecutados y resultados. Mantener el propósito académico del proyecto; añadir evidencia técnica antes de multiplicar funcionalidades. En el portafolio describir solo lo que esté implementado.
