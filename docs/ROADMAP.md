## Decisiones

- Se implementaron los tres repositorios nuevos y las mejoras aprobadas en los nueve repositorios existentes.
- AWS queda aplazado: no se creó cuenta ni se desplegaron recursos cloud.
- Firebase conserva su configuración; no se publicó desde esta tarea.
- Los datos personales del portafolio se conservaron. Las demos usan información sintética.
- Las guías de tecnologías siguen siendo material de práctica, no productos adicionales.
